bridge｜大阪・北浜／TAKA

共感フェーズ

1. 美容室から帰った後、 こんな気持ちになったことはありますか？

  • なんとなく 思っていたのと違う気がしたけれど、 「まあいいか」と帰った言えなかった、という感覚
  • 施術中ずっと 「これでよかったのかな」と 思っていたけれど、言い出せなかった心の中で問い続けていた
  • 「何がしたいか」を聞かれて、 うまく言葉が出てこなかった言葉にならない感覚
  • 特に不満はなかったけれど、 何か物足りない気がした何かが足りない、でも何かは分からない

2. 美容室へ向かうとき、 こんなことを感じたことがありますか？

  • 「今日、うまく伝えられるかな」と 少し緊張しながら向かった行く前から不安がある
  • 「また同じ仕上がりになるだろうな」と どこかで思っていた変わらないことへの諦め
  • 「何をオーダーすればいいか」 が決まらないまま予約をした決め方がわからない
  • 「お任せします」と言いたいけれど、 それでいいのか迷っていた任せることへの不安

言語化フェーズ

3. 髪の悩みを聞かれたとき、どんな感じになりますか？

  • 「広がる」「パサつく」くらいしか 言葉が出てこない悩みを言葉にするのが難しい
  • 悩みはあるけれど、 原因の心当たりが複数あって絞れない悩みが多すぎて整理できない
  • なりたいイメージはあるのに、 それを言葉にできない感覚はあるが言語化できない
  • 自分の髪がどういう状態なのか、 そもそくよく分からない現状把握ができていない

4. 「何か気になることはありますか？」と 聞かれたとき、あなたは？

  • 気になることはあるのに、 「特にないです」と言ってしまう本当のことが言えない
  • 「少し広がりが気になるかも…」と、 一番軽いことだけ言う本当の悩みの手前で止まる
  • 全部話そうとして、 まとまりなく話してしまう伝えたいがうまくまとまらない
  • 「お任せします」と言って、 全部委ねてしまう伝えることを手放してしまう

深層フェーズ

5. 「変えたい」という気持ちはあるのに、 踏み出せない理由は何でしょう？

  • 失敗したとき、後悔することが怖いリスクを取ることへの恐怖
  • 「私の髪質ではどうせ無理」 という気持ちがある自分の髪への諦め
  • 「自分に何が似合うのか」が 本当に分からない似合うの基準が持てない
  • 変えたい気持ちより 「今のままでいいか」が勝ってしまう変化への踏み出せなさ

6. 「本当はこうしたいのに」と思いながら、 諦めていることがありますか？

  • 骨格や顔型のせいで似合わないと思い、 最初から諦めているスタイルがある骨格への諦め
  • ケアを変えたいが 何をどう変えればよいか分からず、 そのままにしているケア迷子の状態
  • 「イメチェンしたい」気持ちはあるが、 自分には難しいだろうと思っている変化への諦め
  • もっと相談したいのに、 時間を取らせて申し訳ないと遠慮している遠慮による諦め

開放フェーズ

7. もし「何でも正直に話せる場所」 があったとしたら、一番伝えたいことは？

  • 「うまく言えないのですが、 こんな感じになりたくて…」という 曖昧な気持ちをちゃんと聞いてほしい
  • 「実は以前、 少し違うなと思ったのですが…」という 言えなかった本音を伝えたい
  • 「私の髪、本当はどんな状態なの？」という 素朴な疑問に向き合ってほしい
  • 「私にはどんなスタイルが似合うのか」を 一緒に探してほしい

8. 美容室との「理想の関係」を 一言で表すとしたら？

  • 「黙っていても分かってくれる」 ——そんな安心感がほしい
  • 「一緒に考えてくれる」 ——そんな伴走者がほしい
  • 「私の可能性を引き出してくれる」 ——そんな存在がほしい
  • 「何でも正直に言える」 ——そんな関係がほしい

6つのタイプ（全文）

Type A ｜ 「遠慮」が言葉を飲み込んでいる

Type A — 気持ちは十分あるんですね。
ただ、言い出せていないだけだと思います。

いま起きていること本当は言いたいことがある。
でも「迷惑をかけたくない」が
先に来てしまうのでは？
くわしくあなたには、
美容師に伝えたい気持ちが確かにあります。
「こうしたい」
「これは違う気がした」
「もっと相談したい」
——その感覚は正しいんです。

でも、「時間を取らせて申し訳ない」
「言ったら感じが悪いかも」「また次回にしよう」
という遠慮の気持ちが、
毎回その言葉を飲み込んでしまっている
と思います。

その遠慮は、あなたの優しさから来ています。
でもその優しさが、あなた自身を
ずっと後回しにさせているかもしれません。
TAKAから「遠慮しなくていいですよ」とお伝えしても、
遠慮してしまうのが人間ですよね。
だから言わせてください。
美容師はあなたの話を聞くために、
そこにいます。
時間を取らせているのではなく、
その時間こそが施術の一部です。
あなたの「言えなかったこと」を、
次回ぜひ持ってきてください。
次にできること次回の来店前に、「一つだけ正直に伝えること」
を決めておきましょう。
全部でなくていい。一つだけでいい。
「実は以前、少し気になっていたのですが…」
——その一言から、関係は変わり始めます。

Type B ｜ 「言葉」がまだ見つかっていないだけ

Type B — 悩みはあるんだけど…。
ただ、言語化の道具がまだ手元にないの。

いま起きていること「うまく言えない」のではなく、
髪の悩みを言葉に変換する機会が
なかっただけだと思います。
くわしく「広がる」「パサつく」
——それしか言葉が出てこないのは、
あなたの言葉の問題ではありません。
ヘアの悩みを言語化するための
「変換する機会」がまだなかっただけです。

美容師は毎日、何十人もの方の
「言葉にならない悩み」を受け取り、
形にしています。
断片的な言葉でも、感覚的な表現でも、
それをくみ取るのがプロです。

「うまく言えないのですが…」という前置きで、
十分に伝わります。
TAKAから「うまく話せなくて申し訳ありません」
と謝られることが、現場でも多いんです。
でも謝らなくていい。
「なんかこう…うまく言えないのですが」、
それで始めてください。
そこから一緒に言葉を探すことができます。
あなたの感覚は、必ず形にできます。
次にできること次回の来店時、「うまく言えないのですが…」
と正直に切り出してみてください。
その後に続く断片的な言葉が、
実は一番大切な情報です。
本当に。
一枚だけ写真を用意していくのも、
言葉の代わりになります。

Type C ｜ 「失敗への恐れ」が変化を止めている

Type C — 変わりたい気持ちは本物。
ただ、怖さが先に来てしまうのかも。

いま起きていること「変えたい」という気持ちは、
ずっとある。でも失敗を想像すると、
一歩が出なくなってしまう。
くわしく「こんなふうにしてみたい」「何か変えたいな」
——その気持ちは大切です。
でも、失敗したときのことを想像すると、
どうしても踏み出せなくなる。

その「怖さ」は正常な感覚です。
過去の経験や髪は顔の印象になるから、
慎重になるのは当然のことです。

ただ、今あなたが失っているのは
「変わらないことのリスク」かもしれません。
変えないまま時間が過ぎることも、
一つの選択だと思います。
TAKAから「失敗が怖い」という気持ち、
すごくよく分かります。
だからこそ伝えたいのは、
失敗しない変え方があるということです。
一気に変えなくていい。「少しだけ試す」
という変え方もあります。
「ちょっとだけ変えてみたいのですが、怖くて」
と、正直に言ってみてください。
その怖さをちゃんと受け止めて、
一緒に進みます。
次にできること「全部変える」ではなく「一部だけ試す」
という発想で考えてみましょう。
前髪だけ、毛先だけ、色味だけ少し
——小さな変化から始めると、怖さは減ります。
「ちょっとだけ変えてみたいのですが」
という一言を、
次回用意しておいてください。

Type D ｜ 「現状把握」ができていないもどかしさ

Type D — 悩みがあることは分かっているの。
でも、何が原因か分からないんです。

いま起きていること「なんか気になる」はある。でも、
それが髪質なのか、ケアなのか、
スタイルなのか、分からない。
くわしく悩みはある。
でもその悩みの「原因」が分からないから、
何をどう相談すればいいかも分からない。
これはとても多い状態です。

「広がるのは、
くせ毛のせい？カットのせい？ケアのせい？」
——原因の仮説が立てられないと、
悩みが悩みのまま堂々巡りしてしまいます。

原因を特定するのは、美容師の仕事です。
あなたが「なぜ」まで分かっている必要は
ありませんし、頼っていいんです。
TAKAから「何が原因か分からなくて」という言葉、
実はとても大事な情報です。
「どこが気になるか」だけ教えていただければ、
原因を探るのは私の仕事です。
「なんか気になるのですが、
原因が分からなくて」
——その一言で十分です。
一緒に整理しましょう。
次にできること「どこが気になるか」だけを
一つ決めてきてください。
「広がりが気になる」「パサつきが気になる」
「なんとなくまとまらない」
——それだけで大丈夫です。
「なぜ」は考えてこなくていい。
それを一緒に探すのが、
コンサルテーション（カウンセリング）です。

Type E ｜ 「自分の髪への諦め」が積み重なっている

Type E — 本当はもっとできるはず。
でも、諦めが先に来てしまっている。

いま起きていること「私の髪だから、どうせ無理」——その言葉を、
知らずに自分に言い聞かせていませんか？
くわしく骨格のせい、くせ毛のせい、量のせい——
「どうせ私の髪では無理」という言葉が、
いつの間にか心に定着してしまっている。

でもその「諦め」は、
本当に正しいのでしょうか？
それは過去の体験からくる思い込みかもしれません。

技術も、素材への理解も、年々変わっています。
一度、その「諦め」を手放してみる機会を
作ってほしいと思っています。
TAKAから「私の髪では無理だろうと思っていました」
と来てくださる方がいます。
でも実際にやってみると
「え、できるんですか！」となることが
本当に多い。
あなたの「諦め」は、
まだ試されていないものかもしれません。
「諦めていたけれど、実はこうしたくて」と、
次回話してみてください。
次にできること「諦めていること」を一つ、
正直に話してみてください。
「こういうスタイル、
私には無理だと思っていたのですが…」
——その一言から、
思いがけない可能性が開くことがあります。
諦めの理由を聞いて、
それが本当かどうかを一緒に確認するのが、
プロの仕事です。

Type F ｜ 「なりたいイメージ」が言葉になっていない

Type F — 感覚はあるの。
でも、それを言葉にする術がまだないんです。

いま起きていること「こんな感じ」という感覚はある。
でも形にできなくて、
いつも「お任せ」になってしまう。
くわしくイメージはある。でも言葉にできない。
だから「お任せします」と言うしかない。
そして返ってきた結果が「なんか違う」
でも、何が違うのかも言えない。

このサイクルは、
「自分のイメージを言語化する機会がなかった」
ことから来ています。

「お任せ」は悪くありません。
でも「お任せ」しながら「こういう雰囲気が好き」
「これは嫌い」という感覚を持ち込めると、
仕上がりは大きく変わります。
TAKAから「お任せします」と言っていただけると、
とても嬉しいんです。でも同時に
「あなたの好きを教えてほしい」とも思います。
言葉じゃなくていい。
「なんかこういう雰囲気が好きで」で十分です。
写真でも、服のテイストでも、
「これは嫌い」という一言でもいい。
あなたの感覚が、最高の素材なんです。
次にできること次回は「お任せ」に一言だけ
足してみてください。
「お任せしますが、こういう雰囲気が好きで」
「お任せしますが、これは嫌いで」
——その一言が、仕上がりを変えます。
好きな雰囲気の写真を一枚だけ持っていくのも、
とても有効です。
